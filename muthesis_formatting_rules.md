# Dissertation Formatting Rules (`muthesis.cls`) — Instructions for Claude Code

> Source: `muthesis.cls` — University of Manchester MU Thesis Class (Dept. of Computer Science), G.D. Gough / University of Manchester.
> This is the **mechanical / template layer**. Use it together with the research-writing guide. Apply these rules to all LaTeX produced for the dissertation.
>
> **Scope note:** Per request, the **Declaration**, **Intellectual Property / Copyright statement**, and **Acknowledgements** are out of scope here. They are part of the class flow (the class auto-generates the Declaration and Copyright pages; Acknowledgements is author-added) and are only flagged below, not detailed.

## Document class and invocation

- The class is built on `report` with `a4paper`.
- For an MSc dissertation, use:

```latex
\documentclass[12pt,MSc]{muthesis}
```

- `12pt` gives acceptable output; omit it for smaller print. Add `twoside` when printing double-sided.
- Use `singlespace` only for draft copies; **remove it before submission**.
- With `MSc`, the degree is *Master of Science* and the document refers to itself throughout as a **"dissertation"** (other degrees call it a "thesis").

### Class options

| Option | Effect |
|---|---|
| `MSc` | Degree = Master of Science; document = "dissertation". |
| `PhD` | Degree = Doctor of Philosophy; document = "thesis". (Default if no degree option given.) |
| `MPhil` | Degree = Master of Philosophy. |
| `MRes` | Degree = Master of Research in Informatics. |
| `EngD` | Degree = Doctor of Engineering; document = "thesis". |
| `singlespace` | Single line spacing (drafts only). |
| `doublespace` | Double line spacing. |
| `wordcount` | Prints a word count (requires a `word.count` file — see below). |
| `anon` | Anonymous submission: prints the student id (set with `\stuid`) instead of the author name. |

- Unrecognised options are passed through to the `report` class.
- The class is **not** compatible with the `drafthead` style.
- Multi-volume dissertations are not supported.

## Page geometry / margins

- **Binding (left-hand) margin: 40 mm.** All **other margins: 25 mm**.
- Hard minimums from the submission rules: binding margin **≥ 40 mm**, all other margins **≥ 15 mm**; page numbers must fall **within** these margins.
- Do **not** use marginal notes — there is little space, they format badly, and they violate the margin rules.
- The class sets text width **145 mm** and text height **224 mm** to achieve this; do not override the geometry.

## Line spacing

- Default spacing is **one-and-a-half** (interline spacing ≈ 1.24× normal), applied document-wide.
- **Figures and tables use normal (single) spacing**; footnotes and quotations are likewise excepted from one-and-a-half spacing.
- Override only via the `singlespace` / `doublespace` class options, not manually.

## Page numbering

- Numbering is **arabic** and **starts on the title page**, which is **page 1**.
- **Every** page is numbered (front matter, lists, body — all included).
- The **title page itself does not display** its page number.
- Body pages use running headings (the chapter title appears at the top of each page).

## Page breaks

- Page breaks at hyphens are disallowed (`\brokenpenalty=10000`). Expect occasional underfull boxes; fix problem breaks manually rather than re-enabling hyphen breaks.

## Required front-matter order

The preface must appear in this order:

1. **Title page**
2. **Contents** — table of contents, then **List of Tables**, then **List of Figures** (this is the correct place for these lists)
3. **Abstract** (short)
4. *Declaration* — out of scope here (auto-generated by the class)
5. *Statement of IP / Copyright* — out of scope here (auto-generated by the class)
6. *Acknowledgements / anything else* — out of scope here (author-added), placed **after** the mandatory preface sections and **before** the first chapter

Then the numbered body chapters, optional appendices, and the bibliography.

## Title page — content and order

The title page (generated by the class) presents, in order:

1. The submission statement — "A dissertation submitted to The University of Manchester for the degree of *Master of Science* in the Faculty of …"
2. **Year of presentation**
3. **Candidate's name** (or student id if `anon`)
4. **Candidate's department**

## Document skeleton

Drive the template with this command sequence. (Declaration, Copyright/IP, and Acknowledgements are omitted per scope; the class still auto-produces the Declaration and Copyright pages at `\afterabstract`.)

```latex
\documentclass[12pt,MSc]{muthesis}

\begin{document}

% --- front-matter setup (see macros below) ---
\title{Your Title\\Second Line If Needed}
\author{Author Name}
\stuid{Student ID}

\beforeabstract            % title page, (sig page if enabled), TOC,
                           % (word count if enabled), List of Tables, List of Figures
\prefacesection{Abstract}
\abstracttitle
  % short abstract text here
\afterabstract             % (Declaration + Copyright/IP pages auto-generated here)

% other preface sections (e.g. Acknowledgements) would go here

\afterpreface              % begins main body, continues numbering, adds headings

\chapter{Introduction}
  % ...
\chapter{Conclusions}
  % ...

\appendix
\chapter{Appendix Title}
  % ...

\bibliographystyle{alpha}
\bibliography{mybib}

\end{document}
```

- Never use one of `\beforeabstract` / `\afterpreface` without the other.
- `\beforeabstract` builds: title page → signature page (if enabled) → table of contents → word count (if `wordcount`) → List of Tables (if enabled) → List of Figures (if enabled).
- `\afterpreface` switches to the main body, continuing page numbering and turning on running headings.

## Front-matter setup macros

| Macro | Purpose / default |
|---|---|
| `\title{...}` | Dissertation title. Use `\\` for multi-line titles. |
| `\author{...}` | Author name. |
| `\stuid{...}` | Student id (used on the title page when `anon` is set). |
| `\department{...}` | Defaults to *Department of Computer Science*. |
| `\faculty{...}` | Defaults to *Science and Engineering*. |
| `\submitdate{...}` | Defaults to the current year. **Year only** — no month required (since July 2003). |
| `\copyrightyear{...}` | Defaults to the current year (next year if submitted in December). |
| `\copyrighttrue` / `\copyrightfalse` | Produce the copyright page. **Default: true.** |
| `\figurespagetrue` / `\figurespagefalse` | Produce the List of Figures. **Default: true.** |
| `\tablespagetrue` / `\tablespagefalse` | Produce the List of Tables. **Default: true.** |
| `\sigpagtrue` / `\sigpagfalse` | Produce a signature page. **Default: false** (Manchester does not require one). |
| `\principaladviser{...}` / `\firstreader{...}` / `\secondreader{...}` | Only used if the signature page is enabled. |

## Abstract

- Keep it **short**.
- Introduce it with `\prefacesection{Abstract}` followed by `\abstracttitle`, which prints a single-spaced title block (title, author, degree statement, submission date) above the abstract text.

## Sectioning

- Use the standard `report` hierarchy: `\chapter`, `\section`, `\subsection`, etc.
- Appendices: switch with `\appendix`, then use `\chapter{...}` for each appendix. There are no special rules on appendix content.

## Bibliography

- No fixed reference format is mandated — be **consistent** in the naming scheme.
- **Recommended style: `alpha`.** Use `\bibliographystyle{alpha}` and `\bibliography{...}`.
- The bibliography automatically gets a table-of-contents entry.

## Word count

To print a word count, add the `wordcount` class option and supply a `word.count` file containing the count. Generate it with `texcount`:

```bash
perl texcount.pl -1 -sum -relaxed -inc report.tex > word.count
```

- `texcount.pl` is available from http://app.uio.no/ifi/texcount/.
- The output file may contain an error message and may need manual editing before use.
- Do **not** run this automatically from within LaTeX (the error message breaks the build).

## Compliance

- Final responsibility for compliance with the University of Manchester **Presentation of Theses Policy** rests with the candidate. Treat the rules above (margins, spacing, page numbering, required front matter) as hard requirements, not defaults to tweak.
